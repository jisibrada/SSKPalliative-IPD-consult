กำลังโหลด...
• เปิด/ปิดใช้งาน = กดปุ่มสถานะ (ปิดแล้วผู้ใช้จะเข้าระบบไม่ได้ทันที)
• ลบสิทธิ์ = ลบโปรไฟล์ออกจาก Firestore ผู้ใช้จะเข้าไม่ได้ แต่บัญชี Authentication ยังอยู่ (ถ้าต้องการลบถาวรต้องลบใน Firebase Console → Authentication)
• เปลี่ยนรหัสผ่านให้คนอื่น ทำจากหน้านี้ไม่ได้ (ข้อจำกัดฝั่ง client) — ทำได้ที่ Firebase Console → Authentication → เลือกผู้ใช้ → Reset password
